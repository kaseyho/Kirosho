## Title

Kirosho — Place existing shelters around the hours people need shade

## Description

Kirosho is a working SPECS Lens for facilities and event planners deciding where to place a limited shelter inventory.

This demonstration uses the actual Lens Studio SPECS 27 Preview with simulated interactions and a fictional Singapore courtyard. It is not footage from physical glasses or a surveyed site.

The prototype combines projected shade with illustrative activity schedules. It evaluates 5,436 permitted placements of two existing shelters and shows each zone's gain or loss before a planner applies a suggestion. In the showcased schedule, aggregate modeled coverage rises from 32.1% to 62.3%; the lunch queue loses coverage while seating and pickup gain it. These are modeled shade results, not measured cooling or carbon savings.

Planned with Devpost Learn and built using Codex, Snap CLAD and Lens Studio MCP, with Spectacles Interaction Kit, Spectacles UI Kit and LEAF. Runtime calculations are local and deterministic.

Project and source: https://github.com/kaseyho/Kirosho

Verification, model assumptions and solar-data attribution are included in the repository. Desktop Preview cadence varies; physical-device performance and field accuracy are untested.
